# Dynamic Resume Builder

A modern, responsive web application built using **HTML**, **CSS**, and **TypeScript** to dynamically generate resumes based on user input. This project was developed as part of the GSIT Milestone 3 assignment.

## 🔗 Live Demo

[View Live App](https://faraz-gsit-dynamic-resume-builder.vercel.app/) (replace with actual deployment link if available)

## 📌 Features

- 🔄 **Real-Time Resume Preview**  
  Instantly displays the resume as the user fills in the form.

- 🧾 **Dynamic Sections**  
  - Personal Information  
  - Education  
  - Skills  
  - Work Experience  
  - About Section

- ✅ **Form Validation**  
  Ensures that all required fields are properly filled before displaying results.

- 🎨 **Responsive Design**  
  Works well on desktops, tablets, and mobile devices.

- 💡 **Interactivity with TypeScript**  
  - Toggle visibility of different sections  
  - Dynamically render user input  
  - Real-time updates without page reload

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3**  
- **TypeScript**
